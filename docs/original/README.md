# Original lm-0.2.5 documentation

These are the source files of the original Language Machine website and release notes, copied verbatim from lm-0.2.5 (© Peri Hankey 2005–2007; documentation under the GNU FDL, code under the GNU GPL v2). The structured digest in `../lm/` was made from the rendered website. Use these files to check that digest against the original wording.

- `*.wiki`: page sources in mediawiki markup, taken from `src/web`. The site was generated from them by `examples/wiki/mediawiki.lm2n`. `picturebook.wiki` and `lm-diagram.wiki` describe the lm-diagram.
- `images/`: `lm-diagram.png`, the `picturebook_*.png` illustrations, and the PDFs: the handwritten notes, the outline, and "a letter to Jonathan Swift". The 58 page scans of the notes (`language_machine_notes0*.png`) were left out because they duplicate `language_machine_notes.pdf`.
- `README`, `ChangeLog`, `TODO`, `NEWS`, `AUTHORS`: the release's top-level files.

The grammars that the pages refer to are in `../../examples/`.
